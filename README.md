# Bug2Code

Bug2Code takes a Jira bug report (title + description) and ranks the source files most likely
to contain the related code:

```
bug report  ->  ranked list of source files
```

This is bug **localization / ranking**, not classification — there's no fixed set of labels,
just an ordering over the files that exist in the project.

TAU Deep Learning capstone, 2026 · Shir Itah & Shaked Tsabari.

## Approach

Four methods, compared on the same Cassandra bug data:

1. **TF-IDF + cosine similarity** — lexical baseline.
2. **Frozen CodeBERT** — pretrained `microsoft/codebert-base`, no training.
3. **Fine-tuned CodeBERT dual encoder** — same base model, fine-tuned on bug/gold-file pairs.
4. **Hybrid** — TF-IDF and Fine-tuned CodeBERT scores combined.

Jira **Component filtering** and **generalization to other projects** (transfer to HBase and
Spark) are evaluated as extensions on top of the selected Fine-tuned CodeBERT model.

**Main takeaway:** fine-tuning helps CodeBERT enormously over using it frozen, but the strongest
single result comes from combining TF-IDF with Fine-tuned CodeBERT — the Hybrid model beats every
method on its own.

## Data

Bug reports come from Apache Jira. For each bug we search the project's git history for the
commit that fixed it; the files it changed are the **gold files** (ground truth). The
**candidate files** are all in-scope source files that existed right before the fix, so the
model never sees the fix itself. The final experiments run on a fixed, deterministic 30% subset
of Cassandra (compute-constrained scope; see `docs/project_documentation.md`).

## Setup

Requires Python ≥ 3.11.

```bash
python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
pip install -e .
```

Apache Jira is readable anonymously and commit linking runs against local git clones, so no API
tokens are required to run the default pipeline.

## Running the project

```bash
python -m bug2code.data.collect_issues        # 1. build the dataset
python -m bug2code.data.build_snapshots
python -m bug2code.data.split

python -m bug2code.localization.train_codebert --config configs/cassandra30.yaml   # 2. fine-tune

python -m bug2code.localization.save_tfidf_test_scores --config configs/cassandra30.yaml  # 3. evaluate
python -m bug2code.localization.hybrid_test_experiment --config configs/cassandra30.yaml

pytest                                          # 4. tests
```

Full command list, in order, and final results: [`docs/project_documentation.md`](docs/project_documentation.md).
